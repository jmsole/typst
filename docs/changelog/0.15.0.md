# Version 0.15.0 (Unreleased) { #v0.15.0 }

## Text
- Added support for variable fonts. Variable fonts can now be used directly
  without needing static font files. Typst interpolates along the font's
  design axes for smooth weight, width, and other transitions.
  - The [`weight`]($text.weight) and [`stretch`]($text.stretch) properties
    now automatically drive the `wght` and `wdth` variation axes on variable
    fonts, enabling continuous interpolation (e.g. `{weight: 350}` now
    produces the exact intermediate weight on a variable font instead of
    snapping to the nearest static instance).
  - Added [`text.variations`]($text.variations) property for setting
    arbitrary OpenType variation axis coordinates. Accepts a dictionary
    mapping four-character axis tags to values, e.g.
    `{variations: (wght: 350, opsz: 24)}`.
  - Explicit `variations` entries take precedence over `weight` / `stretch`
    for rendering, while the latter are still used for font selection.
  - All export formats (PDF, SVG, PNG) fully support variable font rendering.
  - Removed the warning about variable fonts not being supported.
